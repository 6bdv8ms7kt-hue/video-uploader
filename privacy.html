プライバシーポリシー

最終更新日：2026年10月17日

1. 対象

このポリシーは、作成者本人だけが使う動画アップロードツール「Yamato Video Uploader」（以下「本ツール」）に適用されます。本ツールは一般には提供していません。

2. 利用する Google のデータ

本ツールは、作成者本人の Google アカウントで許可された YouTube Data API の範囲 youtube.upload（動画のアップロード）だけを使います。作成者本人の YouTube チャンネルに動画をアップロードする目的以外には使いません。

3. 収集・保存する情報

  • 他人の個人情報は収集しません。
  • 認可に必要なトークンは、作成者本人のパソコンの中にだけ暗号化して保存し、外部には送信しません。
  • アップロードした動画の ID などの記録は、作成者本人のパソコンの中にだけ保存します。

4. 第三者への提供

取得したデータを第三者に販売・共有・提供することはありません。

5. 取り消し

本ツールへのアクセスは、Google アカウントの「サードパーティのアクセス」からいつでも取り消せます。

6. Google API サービスのポリシー

本ツールによる Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。YouTube の利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。

English summary

Yamato Video Uploader is used only by its owner. It requests only the youtube.upload scope and uses it solely to upload the owner's videos to the owner's own YouTube channel. It does not collect personal data from anyone else. OAuth tokens are stored encrypted, and upload records are stored, only on the owner's computer. No data is sold, shared or sent to third parties. Access can be revoked at any time from Google Account third-party access. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube use is subject to the YouTube Terms of Service and the Google Privacy Policy.
